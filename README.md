## Quick Help

### Setting Up API Keys

1. **Gemini API** (for content): Get free key at https://aistudio.google.com/apikey
2. **OpenAI API** (for audio): Get key at https://platform.openai.com/api-keys
3. In Baraja: Settings → paste keys → Test Connection

### Importing to Anki

1. Download Anki from https://apps.ankiweb.net/
2. Find .apkg file in your output folder
3. Drag to Anki or use File → Import

### Common Issues

**Generation fails:**
- Verify API keys with Test Connection
- Check output folder is set and writable
- Ensure topic field is not empty

**No audio:**
- Verify OpenAI API key is valid
- Check voice is selected in Settings

**Can't find .apkg file:**
- Check output folder setting
- Look in Desktop or Documents if unsure

## About Baraja

Baraja Generator creates authentic Mexican Spanish flashcard decks for Anki users. Free forever with your own API keys.

**Features:**
- AI-generated content with authentic Mexican Spanish
- Native-quality audio pronunciation
- Customizable difficulty and length
- Batch generation from CSV
- 6 Anki card themes

**Roadmap:**
- v1.1: Multi-language support (Portuguese, Italian, French)
- v2.0: Baraja Designer (pattern-based curriculum builder)
- v3.0: Baraja Notebook (personal pattern library)
