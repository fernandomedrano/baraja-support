# Support

Need help with Baraja Generator? Here's how to get support:

## Quick Help

**Common Issues:**

### API Key Setup
- **Gemini:** Get free key at https://aistudio.google.com/apikey
- **OpenAI:** Get key at https://platform.openai.com/api-keys (requires payment method)
- Paste keys in Settings tab → Test Connection

### Generation Fails
- Check API keys are valid (Test Connection)
- Ensure output folder is set and writable
- Verify topic is filled in
- Check console output for error messages

### Anki Import Issues
- Download Anki from https://apps.ankiweb.net/
- Find .apkg file in your output folder
- Drag .apkg to Anki or use File → Import

### Audio Not Playing
- Check voice is selected in Settings
- Verify OpenAI API key is valid (TTS requires OpenAI)
- Test with a small deck first

## Get Help

**For bugs, questions, or feature requests:**

1. Visit [GitHub Issues](https://github.com/fernandomedrano/langcaster-2/issues)
2. Click "New Issue"
3. Choose the appropriate template:
   - **Bug Report** - Something isn't working
   - **Feature Request** - Suggest a new feature
   - **Help / Question** - Get usage help
